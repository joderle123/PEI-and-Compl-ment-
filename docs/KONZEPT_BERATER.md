# Konzept: Klinisch-Pädagogischer Berater (KPB)

## Vision
Ein regelbasiertes Expertensystem, das wie ein erfahrener Pedopsychiater/Diplompsychologe denkt und pädagogische Fachkräfte bei der Fallarbeit unterstützt.

---

## 1. Denkweise eines Pedopsychiaters

### 1.1 Klinisches Denken
Ein Pedopsychiater/Diplompsychologe arbeitet nach folgendem Schema:

```
BEOBACHTUNG → HYPOTHESE → EXPLORATION → DIFFERENZIALDIAGNOSE → INTERVENTION
```

**Kernfragen:**
- Was sehe ich? (Symptome/Verhalten)
- Warum zeigt das Kind dieses Verhalten? (Funktion)
- Seit wann? Was hat sich verändert? (Verlauf)
- Was hält das Problem aufrecht? (aufrechterhaltende Faktoren)
- Was sind Ressourcen? (Schutzfaktoren)
- Was könnte es noch sein? (Differenzialdiagnose)

### 1.2 Bio-Psycho-Soziales Modell

## 2. Module des Beratungssystems

### MODUL A: Basisinformationen (bereits vorhanden)
- Stammdaten
- ELDiB-Einschätzung (4 Bereiche, 5 Stufen)

### MODUL B: Entwicklungsanamnese (NEU)
```
B1. Schwangerschaft & Geburt
    - Komplikationen?
    - Frühgeburt?
    - Perinatale Belastungen?

B2. Frühe Entwicklung (0-3 Jahre)
    - Motorische Meilensteine
    - Sprachentwicklung
    - Bindungsverhalten
    - Regulationsfähigkeit (Schlafen, Essen, Schreien)

B3. Kindergartenzeit (3-6 Jahre)
    - Trennungsverhalten
    - Spielverhalten
    - Soziale Integration
    - Auffälligkeiten

B4. Schulzeit
    - Schulreife
    - Lernentwicklung
    - Soziale Entwicklung
    - Kritische Ereignisse
```

### MODUL C: Familienanamnese (NEU)
```
C1. Familienstruktur
    - Wer lebt im Haushalt?
    - Geschwister (Alter, Beziehung)
    - Trennung/Scheidung?
    - Patchwork?

C2. Familiäre Belastungen
    - Psychische Erkrankungen in der Familie?
    - Suchtproblematik?
    - Chronische Erkrankungen?
    - Soziale Belastungen?

C3. Erziehungsstil
    - Strukturgebung
    - Wärme/Zuwendung
    - Konsistenz
    - Elterliche Übereinstimmung

C4. Belastende Lebensereignisse
    - Verluste
    - Traumata
    - Übergänge
    - Aktuelle Stressoren
```

### MODUL D: Klinisches Screening (NEU)
Systematische Erfassung von Symptomclustern:

```
D1. Aufmerksamkeit & Aktivität (ADHS-Spektrum)
    □ Unaufmerksamkeit
    □ Hyperaktivität
    □ Impulsivität
    → Ausprägung: leicht / mittel / stark
    → Situationsübergreifend: ja / nein

D2. Ängste & Sorgen (Angststörungen)
    □ Trennungsangst
    □ Soziale Ängste
    □ Spezifische Phobien
    □ Generalisierte Ängste
    □ Schulangst/verweigerung

D3. Stimmung & Antrieb (Affektive Störungen)
    □ Traurigkeit
    □ Interessenverlust
    □ Reizbarkeit
    □ Antriebslosigkeit
    □ Schlafprobleme
    □ Suizidale Gedanken (!)

D4. Soziale Interaktion (Autismus-Spektrum)
    □ Blickkontakt-Besonderheiten
    □ Schwierigkeiten mit Gegenseitigkeit
    □ Eingeschränkte Interessen
    □ Rituale/Routinen
    □ Sensorische Besonderheiten

D5. Oppositionelles/Dissoziales Verhalten
    □ Regelübertretungen
    □ Aggression
    □ Lügen/Stehlen
    □ Empathiemangel
    □ Schuldzuweisungen

D6. Trauma & Belastung
    □ Bekanntes Trauma?
    □ Wiedererleben
    □ Vermeidung
    □ Übererregung
    □ Dissoziation

D7. Bindung & Beziehung
    □ Bindungsmuster (sicher/unsicher-ambivalent/unsicher-vermeidend/desorganisiert)
    □ Beziehungsfähigkeit
    □ Vertrauen zu Erwachsenen
```

### MODUL E: Funktionale Verhaltensanalyse (erweitert)
```
E1. Verhaltenstopographie
    - Was genau passiert? (beobachtbar)
    - Häufigkeit
    - Dauer
    - Intensität

E2. Auslöser (Antecedents)
    - Situative Auslöser
    - Personenbezogene Auslöser
    - Zeitliche Muster
    - Interne Zustände (Müdigkeit, Hunger, Überforderung)

E3. Konsequenzen
    - Was passiert danach?
    - Kurzfristige Konsequenzen
    - Langfristige Konsequenzen
    - Reaktionen der Umwelt

E4. Vermutete Funktion
    ○ Aufmerksamkeit erhalten
    ○ Etwas Unangenehmes vermeiden
    ○ Etwas Gewünschtes erhalten
    ○ Sensorische Stimulation
    ○ Kontrolle/Autonomie
    ○ Emotionsregulation

E5. Aufrechterhaltende Faktoren
    - Was hält das Verhalten aufrecht?
    - Verstärkermechanismen
    - Systemische Faktoren
```

### MODUL F: Ressourcen & Schutzfaktoren (NEU)
```
F1. Kindebene
    - Stärken
    - Interessen
    - Talente
    - Erfolge
    - Bewältigungsstrategien

F2. Familienebene
    - Unterstützende Bezugspersonen
    - Positive Familienrituale
    - Erziehungskompetenzen
    - Materielle Ressourcen

F3. Soziale Ebene
    - Freundschaften
    - Vereinszugehörigkeit
    - Unterstützungsnetzwerk
    - Professionelle Helfer
```

## 3. Beratungslogik (Regelbasiert)

### 3.1 Entscheidungsbaum
```
                    ┌─────────────────────┐
                    │  ELDiB + Anamnese   │
                    │     eingegeben      │
                    └──────────┬──────────┘
                               ▼
                    ┌─────────────────────┐
                    │ Automatische        │
                    │ Musteranalyse       │
                    └──────────┬──────────┘
                               ▼
         ┌─────────────────────┴─────────────────────┐
         ▼                                           ▼
┌─────────────────┐                       ┌─────────────────┐
│ Entwicklungs-   │                       │ Klinische       │
│ verzögerung?    │                       │ Symptome?       │
└────────┬────────┘                       └────────┬────────┘
         ▼                                         ▼
┌─────────────────┐                       ┌─────────────────┐
│ → ELDiB-basierte│                       │ → Screening-    │
│   Förderung     │                       │   basierte      │
│                 │                       │   Hypothesen    │
└────────┬────────┘                       └────────┬────────┘
         │                                         │
         └────────────────┬────────────────────────┘
                          ▼
                ┌─────────────────────┐
                │ Differenzial-       │
                │ diagnostische       │
                │ Überlegungen        │
                └──────────┬──────────┘
                           ▼
                ┌─────────────────────┐
                │ Priorisierte        │
                │ Empfehlungen        │
                └─────────────────────┘
```

### 3.2 Ausgabe des Systems

**A. Zusammenfassende Einschätzung**
- Entwicklungsstand pro Bereich
- Hauptproblematik
- Differenzialdiagnostische Überlegungen

**B. Hypothesen zur Ätiologie**
- Mögliche Ursachen (priorisiert)
- Aufrechterhaltende Faktoren
- Schutzfaktoren

**C. Empfehlungen**
1. **Sofortmaßnahmen** (Was kann die Schule/KiTa tun?)
2. **Mittelfristige Maßnahmen** (Therapie, Beratung)
3. **Abklärungsbedarf** (Wann zum Spezialisten?)

**D. Konkrete Interventionen**
- Basierend auf ELDiB-Stufe
- Passend zur Problematik
- Mit Materialhinweisen

**E. Gesprächsleitfäden**
- Für Elterngespräche
- Für Lehrergespräche
- Für Teamgespräche

## 6. Differenzialdiagnostische Entscheidungsregeln

### Beispiel: Unaufmerksamkeit
```
WENN: Unaufmerksamkeit = hoch
  UND: Hyperaktivität = hoch
  UND: Situationsübergreifend = ja
  UND: Beginn < 7 Jahre
DANN: Hypothese "ADHS" → Empfehlung: Fachärztliche Abklärung

WENN: Unaufmerksamkeit = hoch
  UND: Nur in Schule
  UND: Angst-Screening = auffällig
DANN: Hypothese "Schulangst" → Empfehlung: Angstbehandlung

WENN: Unaufmerksamkeit = hoch
  UND: Sozialer Rückzug = ja
  UND: Interessen eingeschränkt = ja
DANN: Hypothese "ASS" → Empfehlung: Autismus-Diagnostik
```

5. Regelbasierte Empfehlungen (Intervention)
